Method structure

cilab/ and exp01 to exp04
One measurementbits per byte of a model on fixed text, then the delta against its family base
Part 1: Scoring pipelinecilab/text.py, score.py, stats.py
  1. Step 1Tokenize the corpus with no special tokens; pick the doc-start token from the tokenizer config
  2. Step 2Cut into 1024-token windows; move a boundary left if it would split a UTF-8 character
  3. Step 3One fp16 forward pass per window; −log₂ p of every token from an fp32 log-softmax
  4. Step 4Σ bits ÷ bytes = bpb; Δ % against the family base; 5000 paired window resamples for the 95 % CI
Part 2: Experiments on topsame code on both machines
  1. exp014 pairs, RAW and chat-template conditions, Mac M2 Pro on MPS
  2. exp02Temperature grid 0.50 to 1.60 in 23 steps; fit on even windows, score odd windows
  3. exp0314 checkpoints in one AAU job; Δ per stage against the family base
  4. exp0418 checkpoints through lm-evaluation-harness, 11,433 docs each; correlate Δbpb with loss and gain
What never changes between experimentsThe four corpus snapshots, the window rule, the doc-start rule, the bootstrap, and the scoring code. Only the model list and the question change, so every number is comparable with every other.
Deltas are taken only within a tokenizer family, on identical token ids, so bytes and tokens cancel and the delta is a change in KL divergence.
