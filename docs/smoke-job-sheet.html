Job structure

infra/slurm/smoke.sbatch
ci-smokeone GPU, 30 minutes, proves the pipeline end to end
Part 1: Front endfile operations only, no compute
  1. Step 1git pull --ff-only on the checkout
  2. Step 2Refuse if any tracked file is modified
  3. Step 3Record the commit hash in a new run folder
  4. Step 4sbatch the script; log goes to the run folder
Part 2: Compute nodeholds the GPU from here to exit
  1. Step 5Copy the corpora into the run folder
  2. Step 6singularity exec --nv the shared PyTorch image
  3. Step 7Venv on top of the image; pip is cached after v1
  4. Step 8Print torch, CUDA, GPU name, transformers
  5. Step 9cilab.smoke: GPT-2 on enwik8 → smoke.json
  6. Step 10Exit; Slurm releases the GPU
What it provesCode from one commit runs on a compute node inside the approved container, sees the GPU, downloads a model into the shared cache, and reproduces the Mac reference of 1.243 bits per byte within 0.01. Nothing else.
Steps 1 to 4 touch no compute. Any failure in steps 5 to 10 ends the job because of set -euo pipefail, which releases the GPU.
